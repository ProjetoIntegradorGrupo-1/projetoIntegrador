## História

**Como** Supervisor Operacional  
**Eu quero** criar e editar modelos de checklist com perguntas dinâmicas e tipagens flexíveis  
**Para que** a empresa possa aplicar vistorias para diferentes tipos de veículos e condições de operação  

---

## Critérios de Aceitação

- [x] **Cenário 1 (Criação Dinâmica):** Formulário `frontend/criarChecklist.html` permite adicionar N perguntas via JavaScript e envia os dados ao `backend/criar_checklist_dinamico.php`, que persiste o cabeçalho em `Checklists` e cada pergunta em `Perguntas` via transação PDO atômica.
- [x] **Cenário 2 (Edição Dinâmica de Perguntas):** Tela `frontend/editarChecklist.php` carrega o checklist e todas as perguntas gravadas no banco; permite editar enunciado, categoria e tipo, além de adicionar novas perguntas, persistindo via `backend/processar_edicao_checklist.php`.
- [x] **Cenário 3 (Inativação de Modelo):** Tela `frontend/excluirChecklist.php` permite inativar o checklist sem deletar vistorias antigas já realizadas (`status = 'inativo'`).
