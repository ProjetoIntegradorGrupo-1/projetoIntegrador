## História

**Como** Gestor do Sistema  
**Eu quero** cadastrar, editar dados cadastrais e inativar logicamente usuários  
**Para que** a equipe mantenha permissões atualizadas sem romper o histórico de vistorias passadas  

---

## Critérios de Aceitação

- [x] **Cenário 1 (Cadastro Completo):** O formulário `frontend/caduser.html` envia dados para `backend/processar_cadastro.php`, gravando dados em `Usuarios` com senha criptografada.
- [x] **Cenário 2 (Edição Dinâmica):** A tela `frontend/editarUsuario.php` lista usuários ativos via PDO; ao selecionar um usuário, carrega seus dados atuais para edição e envia ao `backend/processar_edicao_usuario.php`.
- [x] **Cenário 3 (Exclusão Lógica / Soft Delete):** A tela `frontend/excluirUsuario.php` exige confirmação e aciona `backend/processar_exclusao_usuario.php`, que define `ativo = 0`, preservando integridade das vistorias.
