## História

**Como** Supervisor de Frota  
**Eu quero** cadastrar novos veículos, atualizar dados técnicos (odômetro, ano, chassi) e inativar veículos baixados  
**Para que** os motoristas realizem vistorias com os dados corretos de cada veículo em circulação  

---

## Critérios de Aceitação

- [x] **Cenário 1 (Cadastro de Veículo):** Formulário `frontend/cadcar.html` envia campos (placa, marca, modelo, ano, cor, km, renavam, chassi) para `backend/processar_cadastro_veiculo.php` e persiste em `Veiculos`.
- [x] **Cenário 2 (Edição Dinâmica):** Tela `frontend/editarVeiculo.php` carrega veículos do banco em tempo real via PDO e submete alterações validadas para `backend/processar_edicao_veiculo.php`.
- [x] **Cenário 3 (Inativação Lógica):** Tela `frontend/excluirVeiculo.php` permite selecionar veículo ativo e enviar requisição para `backend/processar_exclusao_veiculo.php`, alterando status para `inativo`.
