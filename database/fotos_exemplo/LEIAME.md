# Fotos de exemplo

Fotos dos veículos e das vistorias que estão no `axion_db_completo.sql`.

As fotos enviadas pelo sistema ficam em `uploads/`, e essa pasta não vai para o GitHub.
Quando uma foto não está em `uploads/`, o sistema procura aqui. Assim, quem importa o banco
de exemplo já vê os carros com foto.

São fotos só para ilustrar a demonstração do projeto.
